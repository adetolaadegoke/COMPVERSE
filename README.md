# CAMPVERSE

### Every Campus. One Universe.

CAMPVERSE is a social networking platform designed
for students of private universities in Nigeria.

## Design

- Black
- Gold
- White

## Platforms

- Web
- Laptop
- Android
- iPhone

## Main modules

- Student registration
- Student admission verification
- University directory
- Social media feed
- Photos and videos
- Stories
- Likes and comments
- Private messaging foundation
- Video calling foundation
- Live streaming foundation
- Virtual gifts foundation
- Wallet foundation
- Paystack payment foundation

## Technology

Frontend:
HTML, CSS, JavaScript

Backend:
Node.js and Express

Database:
Supabase PostgreSQL

Authentication:
Supabase Auth

Payments:
Paystack

## Local installation

Install Node.js.

Open the project folder in a terminal.

Run:

npm install

Copy .env.example to .env.

Add your Supabase credentials.

Run:

npm run dev

Open:

http://localhost:3000

## GitHub deployment

Upload the complete project to GitHub.

GitHub Pages cannot run the Express backend.

Deploy the application to a Node.js hosting provider.

## Security

Never upload secret keys to GitHub.

Never expose the Supabase service role key.

Never trust browser-side payment confirmation.

Admission documents must remain private.

Wallet transactions must be processed server-side.
